# Hala Talab Admin — Stage 29 Mobile Core

هذه المرحلة مبنية مباشرة على Stage 28، وتركّز فقط على أهم وظائف الإدارة على الهاتف والآيباد بدون تغيير Backend أو SQL.

## ما تم في Stage 29
- تحسين نافذة القفل/التنبيهات المهمة لتصبح شاشة كاملة على الهواتف، مع Safe Area للآيفون.
- فصل داخل القفل بين: الكل، استرجاع PIN، وطلبات الانضمام.
- إبقاء الضغط على إشعار PIN يفتح صفحة استرجاع العميل أو الشركاء مباشرة.
- إبقاء الضغط على طلب متجر/سائق جديد يفتح صفحة المتجر/السائق وتفاصيل الطلب مباشرة.
- إضافة وصول سريع للموبايل والآيباد من الصفحة الرئيسية إلى PIN العملاء، PIN الشركاء، تسجيل المتاجر، وتسجيل السائقين.
- تحويل جدول استرجاع PIN إلى بطاقات على الشاشات الصغيرة، مع أزرار إصدار/عرض الرمز والرفض بحجم لمس مناسب.
- دعم هواتف صغيرة حتى 390px، هواتف عادية، وأجهزة لوحية حتى 1024px، مع Portrait/Landscape.
- Windows لم يتغير من ناحية الوظائف؛ الإضافات الأساسية تظهر فقط تحت 1024px.

## مهم
لا يوجد SQL جديد في Stage 29. لا تشغّل أي ملف SQL إضافي لهذه المرحلة.
