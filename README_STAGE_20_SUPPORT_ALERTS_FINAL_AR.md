# Admin Stage 20 — تنبيهات الدعم النهائية

- جرس الإدارة صار يلتقط رسائل دعم المتجر/السائق أيضًا، وليس دعم العميل فقط.
- Realtime يعيد تحميل عداد الجرس فور وصول رسالة حتى لو كانت لوحة الإدارة في صفحة أخرى.
- فتح إشعار الدعم يفتح التذكرة الصحيحة ويعلّم الرسائل الواردة كمقروءة.
- إزالة تكرار زر «الدعم» في فلتر مركز التنبيهات.
- اتجاه فقاعات محادثة الدعم ثابت وواضح.
