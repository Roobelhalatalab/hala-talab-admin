هلا طلب — Stage 64 — تحديث واجهة المنيو الإلكتروني
التاريخ: 2026-10-01

تم تنفيذ الملاحظات الثلاث دفعة واحدة:
1) أقسام المنيو:
- العنوان أصبح: منيو [اسم المطعم]
- السطر الصغير: اختر وجبتك
- الأقسام صفّان/عمودان (قسمان في كل صف) بشكل Responsive
- صورة القسم تؤخذ من الصورة المضافة للقسم في المتجر
- عند عدم وجود صورة يظهر رمز طبق/شوكة/ملعقة كبديل

2) الوجبات داخل القسم:
- بطاقات أصغر بدل العرض الكبير
- موبايل: وجبتان في كل صف
- iPad/Tablet: ثلاث وجبات في كل صف
- الحفاظ على اسم الوجبة والسعر وبقية معلومات البطاقة الحالية

3) بطاقة معلومات المطعم العليا:
- إزالة بطاقات: التقييم، وقت التوصيل، رسوم التوصيل، معلومات المطعم
- إبقاء ساعات العمل فقط، مأخوذة من بيانات المتجر/الشفت الحالية

مهم:
- لم يتم تغيير مصدر البيانات أو Supabase أو Realtime أو QR.
- الملفات المعدلة فقط: menu.html, menu.css, menu.js
