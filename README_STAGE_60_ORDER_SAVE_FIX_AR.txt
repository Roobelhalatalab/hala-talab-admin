Stage 60 — إصلاح حفظ ترتيب المطاعم والمتاجر

المشكلة المؤكدة:
- فحص Supabase أظهر أن display_order بقي NULL لكل المطاعم رغم الحفظ من لوحة الإدارة.
- السبب أن الحفظ كان يحدث بتحديث مباشر على stores وقد يمنعه RLS بدون خطأ ظاهر للمستخدم.

الإصلاح:
- إضافة RPC إداري آمن admin_set_store_display_order_v60.
- لوحة الإدارة تحفظ الترتيب عبر الـ RPC بدل التحديث المباشر.
- إبقاء customer_catalog_stores مرتبًا حسب display_order.
- المطاعم والمتاجر تبقى منفصلة، وكل قسم له ترتيب 1،2،3 مستقل.
- لم يتم تعديل OneSignal أو service-worker.js أو مسار إشعارات الإدارة.

بعد الرفع:
1) شغّل _setup/STAGE_60_FIX_STORE_ORDER_SAVE.sql مرة واحدة.
2) افتح لوحة الإدارة وحدد ترتيب مطعم: 1 واحفظ.
3) تحقق في Supabase أن display_order أصبح 1 بدل NULL.
4) أغلق تطبيق العميل وافتحه لاختبار الترتيب.
