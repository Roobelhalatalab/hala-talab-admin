هلا طلب - النسخة النهائية للواجهة فقط

هذه الحزمة مخصصة لرفع ملفات لوحة الإدارة إلى GitHub Pages فقط.
لا تحتوي SQL ولا Edge Function ولا أي أسرار.
لا تحتاج تغيير إعدادات Supabase أو OneSignal.

التعديلات:
- OneSignal SDK هو المسؤول الوحيد عن تسجيل Service Worker (تمت إزالة التسجيل المكرر من الصفحة).
- تفعيل الإشعارات: إذن مرة واحدة ثم optIn، بدون optOut/optIn إجباري أثناء الإصلاح.
- فحص فعلي للـ Subscription ID و Push Token مع انتظار التسجيل.
- يعمل بنفس المنطق على iPhone/iPad PWA وAndroid المتوافق مع Web Push.
- زر واتساب يفتح رقم صاحب طلب PIN مباشرة ويحوّل الرقم العراقي المحلي 07... إلى 9647... تلقائيًا.
- رسالة واتساب:
  رمز استرجاع PIN الخاص بحساب هلا طلب هو: XXXX
  صلاحية الرمز 30 دقيقة.
  يرجى عدم مشاركة الرمز مع أي شخص.
- زر اتصال ونسخ الرمز موجودان بجانب واتساب بعد إصدار الرمز.
