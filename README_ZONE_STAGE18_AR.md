المرحلة 18: نقل الزون بتأكيد آمن.
1) لم تُنفذ أي SQL على قاعدة البيانات.
2) عند النشر نفّذ SQL المرحلة 16 المحدث المرفق، ثم SQL المرحلة 18.
3) معاينة النقل ترجع بصمة إعدادات التوصيل والزون الأصلي.
4) عند التأكيد، إذا تغير الزون أو إعدادات التوصيل يرفض النقل ويطلب إعادة المعاينة.
5) هذا يحمي التعديلات على السجلات الموجودة؛ إدراج منطقة جديدة بالتزامن يحتاج قفل مشترك في دالة حفظ التغطية أيضاً قبل الإنتاج.
6) لم يتم اختبار الواجهة على متصفح أو Supabase، وتم فحص JavaScript فقط.
