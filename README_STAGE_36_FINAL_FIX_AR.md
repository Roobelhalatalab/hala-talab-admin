# هلا طلب — Stage 36 Final Fix

هذه النسخة مبنية على Stage 36 نفسها وليست مشروعًا جديدًا.

## ما تم إصلاحه
- زر إشعارات الهاتف لم يعد يعتمد على Permission فقط.
- الحالة ✅ تظهر فقط عندما تكون Permission + optedIn + Subscription ID + Push Token كلها موجودة فعليًا.
- إضافة حالة ⚠️ عند وجود إذن لكن الاشتراك/التوكن يحتاج إعادة ربط.
- إضافة إدارة حقيقية للإشعارات: إعادة ربط + إيقاف + تشغيل.
- تفعيل `autoResubscribe: true` في OneSignal حسب توصية Web SDK v16.
- الاستماع لتغييرات PushSubscription وتحديث الأيقونة تلقائيًا.
- بعد إصدار PIN تظهر أزرار: واتساب برسالة جاهزة تحتوي الرمز، اتصال مباشر، ونسخ الرمز.
- رقم واتساب/الاتصال يُؤخذ من رقم صاحب طلب PIN نفسه، ولا يوجد رقم مستخدم hard-coded.
