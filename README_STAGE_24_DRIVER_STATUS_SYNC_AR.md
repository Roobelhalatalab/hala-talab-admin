# Hala Talab Admin — Stage 24
## مزامنة حالة السائق والإيقاف النهائي

هذه المرحلة مبنية فوق Admin Stage 23 ولا تغيّر قواعد الطلبات أو المصادقة أو الخرائط.

### الإصلاحات
- فصل **حالة حساب السائق التشغيلية** عن **قرار مراجعة السائق** داخل الجدول.
- إضافة عمود مستقل لحالة الحساب: نشط / موقوف مؤقتًا / موقوف نهائيًا / تحت المتابعة.
- إبقاء عمود المراجعة مستقلًا: قيد المراجعة / مقبول / مرفوض.
- تعديل بطاقات أعلى صفحة السائقين لتعرض الحالات التشغيلية الحقيقية بدل عدادات المراجعة.
- إضافة فلتر مستقل لحالة الحساب.
- بعد الإيقاف أو إعادة التفعيل، تعتمد الواجهة مباشرة على `admin_user_controls` بدل أن تبقى تعرض حالة المراجعة القديمة.
- توضيح أن «الإيقاف النهائي» **حظر تشغيلي دائم مع إبقاء السائق في السجل الإداري** لحماية تاريخ الطلبات، وليس حذفًا لبياناته التاريخية.

### SQL
لا يوجد SQL جديد في Stage 24.
تعتمد المرحلة على SQL الذي تم تشغيله سابقًا في Stage 23 وملف الإجراءات النهائية الموجود أصلًا بالمشروع.

### اختبار سريع
1. افتح السائقين.
2. اختر سائقًا نشطًا.
3. نفّذ إيقافًا مؤقتًا أو نهائيًا.
4. أغلق التفاصيل.
5. يجب أن تتغير حالة الحساب والعداد العلوي مباشرة.
6. قرار المراجعة يبقى كما هو ولا يختلط بحالة الحساب.
