# Hala Talab Admin Stage 21

إصلاحات هذه المرحلة:

1. **صورة تصنيف العميل**: عند تعديل تصنيف موجود ورفع صورة جديدة، تُحفظ `image_url` مباشرة في `system_categories` بعد نجاح الرفع، بدون الاعتماد على خطوة حفظ ثانية قد تُنسى. كما تعرض اللوحة معاينة للصورة داخل جدول التصنيفات.
2. **Realtime للتصنيفات**: ملف SQL يحاول إضافة `system_categories` إلى `supabase_realtime` إذا لم تكن مضافة، حتى يستقبل Client Stage 78 التغيير فورًا.
3. **بيانات العميل**: `admin_list_users()` يقرأ الاسم والهاتف من `raw_user_meta_data` (`full_name` و`contact_phone`) عندما لا يوجد ملف في `partner_profiles`، وهذا يطابق طريقة حفظ بيانات العميل الحالية.
4. **إشعارات الإدارة**: الترتيب صار زمنيًا بوضوح: **الأحدث أولًا ثم الأقدم**. الأولوية تستخدم فقط عند تساوي الوقت.
5. محادثات الدعم نفسها تبقى: **الأقدم فوق والجديد تحت** داخل المحادثة، وهو السلوك الصحيح للمحادثات.
