# Stage 12 — تعديل التصنيفات مع بقاء الربط

هذه المرحلة تجعل تعديل تصنيفات العميل من لوحة الإدارة واضحًا وآمنًا للربط الديناميكي.

- زر **✏ تعديل** ظاهر لكل تصنيف.
- التعديل يشمل العربي/الكردي/الإنجليزي، الأيقونة، الصورة، اللون، الترتيب والحالة.
- التعديل يتم على نفس سجل `system_categories` ولا ينشئ سجلًا جديدًا.
- يبقى `id` / `system_category_id` نفسه، لذلك المتاجر المرتبطة بالتصنيف وتصفية العميل لا تنكسر.
- عند الضغط على تعديل تنتقل الصفحة تلقائيًا إلى نموذج التعديل.

## قبل الاختبار
شغّل مرة واحدة في Supabase SQL Editor:

`admin_stage12_linked_category_edit.sql`

يجب أن تظهر نتيجة:

`linked_category_edit_ready = true`

## اختبار الربط الكامل
1. عدّل اسم/صورة/لون تصنيف مثل «مخابز» من الإدارة واحفظ.
2. افتح تطبيق المتجر Stage 126 وتأكد أن نفس التصنيف يظهر بالتعديل الجديد.
3. أنشئ/أكمل متجرًا واربطه بنفس التصنيف.
4. افتح العميل Stage 40 وتأكد أن التصنيف المعدل يظهر، وأن الضغط عليه يعرض المتاجر المرتبطة به.
