# Admin Stage 25 — كوبونات هلا طلب المركزية + التحسين النهائي

- إنشاء كوبون مركزي من لوحة الإدارة لكل المتاجر الحالية والجديدة.
- حد استخدام عالمي مثل أول 20 / 60 / 100 طلب.
- حد استخدام لكل عميل، وخيار «للعميل الجديد/أول طلب فقط».
- نسبة أو مبلغ ثابت، حد أدنى، سقف خصم، وتواريخ بداية/نهاية.
- مزامنة تلقائية مع المتاجر الجديدة.
- فصل كوبونات هلا طلب عن كوبونات المتاجر داخل الواجهة.
- تحسين وضوح أرقام الرئيسية، الجداول، وحالات الطلبات بدون إعادة تصميم الصفحات.
