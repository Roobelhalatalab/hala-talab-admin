# هلا طلب — لوحة الإدارة (النسخة النهائية النظيفة)

هذه النسخة مبنية على آخر نسخة تم فحصها واعتمادها، مع تنظيف ما قبل الإطلاق بدون تغيير الوظائف التي نجحت في الاختبار.

## ما تم تنظيفه
- إزالة جميع تسميات التطوير الظاهرة للمستخدم مثل Admin Polish / Polish من الواجهات والتقارير.
- استخدام تسميات إنتاجية: **إدارة هلا طلب** و **لوحة الإدارة**.
- الإبقاء على تصميم وطباعة تقرير A4 النهائية (3 بطاقات في الصف الأول و2 في الثاني) لمنع قص أي بطاقة.
- الإبقاء على تحسينات الأقسام والعمولات والاشتراكات والكوبونات والعروض والصيانة والإشعارات والمتاجر والسائقين والمستخدمين والأمان والصلاحيات.
- حذف ملفات النسخ الاحتياطية وملفات ملاحظات A4 المتكررة من مجلد المشروع.
- عدم تغيير إعدادات Supabase أو الوظائف التي سبق اختبارها.

## التشغيل
1. افتح المجلد في VS Code.
2. شغّل `index.html` بواسطة Live Server.
3. إذا كنت قادمًا من آخر نسخة اختبرتها، لا تحتاج إلى SQL جديد.

> ملفات SQL التاريخية موجودة فقط لدعم إعداد قاعدة بيانات جديدة أو استرجاع بيئة قديمة. لا تعِد تشغيلها على قاعدة البيانات الحالية بلا حاجة.


## Hala Talab Admin Fainal
- إضافة زر تفعيل المتجر بعد قبول الإدارة عندما تكون الحالة التشغيلية غير نشطة.
- توسيع مركز الإشعارات ليشمل الطلبات والمتاجر والمستخدمين والسائقين والدعم.
- إظهار المتاجر المقبولة التي تنتظر التفعيل كتنبيه إداري.

- لا يحتاج هذا التحديث SQL جديد إذا كانت ملفات الإدارة النهائية السابقة مطبقة بالفعل.
