# Stage 10 — تصنيفات واجهة العميل

تم فصل **تصنيفات واجهة العميل الرئيسية** عن **أقسام منتجات المتاجر**.

## الجديد في لوحة الإدارة
- تبويب: `تصنيفات العميل`.
- زر واضح: `+ إضافة تصنيف جديد`.
- الاسم عربي/كردي/إنجليزي.
- أيقونة، رابط صورة، لون، ترتيب، وتفعيل/إيقاف.
- تعديل وحذف التصنيف.

## قبل الاختبار
شغّل مرة واحدة في Supabase SQL Editor:

`admin_stage10_client_categories.sql`

ثم افتح لوحة الإدارة → إدارة النظام → تصنيفات العميل.

## الربط مع تطبيق العميل
التصنيفات الفعالة تُقرأ من:

`public.system_categories`

مرتبة حسب `sort_order`.

إذا كانت نسخة العميل الحالية تقرأ `system_categories` فهي ستظهر مباشرة بعد الإضافة/التفعيل. إذا كانت النسخة الحالية ما زالت تحتوي التصنيفات بشكل ثابت داخل Flutter، يلزم تعديل صغير في تطبيق العميل لقراءتها من هذا الجدول؛ لا يمكن للوحة الإدارة وحدها تغيير كود Flutter الثابت.
