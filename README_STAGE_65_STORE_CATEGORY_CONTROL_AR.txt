هلا طلب — Stage 65 — ملاحظة 2

الهدف:
- الإدارة تحدد التصنيف الرئيسي الصحيح لكل متجر/مطعم.
- stores.system_category_id هو المرجع الأساسي لتطبيق العميل.
- منع ظهور متجر سفريات أو ماركت داخل المطاعم بسبب تخمين الاسم أو business_type.

بعد رفع هذه النسخة:
1) شغّل _setup/STAGE_65_STORE_CATEGORY_CONTROL.sql مرة واحدة في Supabase SQL Editor.
2) افتح لوحة الإدارة > المطاعم والمتاجر > تفاصيل المتجر.
3) اختر "التصنيف الصحيح" واضغط "حفظ التصنيف".
4) تطبيق العميل Stage 415 يعرض المتجر فقط عندما يطابق category id فعليًا.

لم يتم تعديل الطلبات أو الإشعارات أو السائق أو الطباعة أو تسجيل الدخول.
