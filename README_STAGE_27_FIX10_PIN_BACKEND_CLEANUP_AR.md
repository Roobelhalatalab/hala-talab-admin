# Stage 27 FIX10 — تنظيف Backend لاسترجاع PIN

هذا الإصلاح Backend فقط. لا يغيّر واجهة لوحة الإدارة ولا يحتاج حذف أو استبدال التطبيق الحالي.

المشكلة التي يعالجها:
`column reference "request_id" is ambiguous`

السبب كان داخل RPC إصدار رمز الاسترجاع، لأن `request_id` كان اسم عمود إرجاع واسم عمود جدول داخل نفس الدالة.

الحل:
- حذف تعريف RPC القديم لنفس التوقيع ثم إنشاء تعريف واحد نهائي.
- إزالة صيغة `ON CONFLICT(request_id)` من داخل الدالة واستبدالها بـ update ثم insert عند عدم وجود السجل.
- إبقاء قاعدة FIX9 كما هي: نفس رمز الاسترجاع للحساب + الدور لمدة 30 دقيقة.
- عدم لمس واجهة الإشعارات أو روابط القفل أو Realtime.
