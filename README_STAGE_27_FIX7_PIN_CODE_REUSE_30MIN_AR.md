# Stage 27 FIX7 — نفس رمز استرجاع PIN لمدة 30 دقيقة

تم تعديل دورة استرجاع PIN حتى لا يتغير الرمز أثناء نافذة الصلاحية:

- إذا طلب العميل/المتجر/السائق «نسيت PIN» أكثر من مرة خلال نفس الطلب المفتوح، لا يتم إنشاء طلب جديد.
- بعد أن تصدر الإدارة الرمز، يبقى **نفس الرمز نفسه** صالحًا حتى انتهاء 30 دقيقة.
- إذا أغلقت الإدارة نافذة الرمز ثم رجعت وضغطت «عرض نفس الرمز»، يظهر نفس الرمز ولا يتم توليد رمز آخر.
- الرمز الجديد لا يصدر إلا بعد انتهاء الرمز السابق أو انتهاء دورة الطلب.
- بعد نجاح تغيير PIN يتم إنهاء الطلب وحذف نسخة عرض الرمز.

## المطلوب
شغّل الملف التالي مرة واحدة في Supabase SQL Editor:

`admin_stage27_fix7_pin_code_reuse_30min.sql`

## ملاحظة مهمة لأول اختبار بعد FIX7
إذا كان هناك رمز تم إصداره **قبل تشغيل FIX7**، قاعدة البيانات القديمة كانت تحفظ الـhash فقط ولا يمكن استرجاع نص الرمز القديم. لذلك أول ضغط على طلب قديم قد يولد رمزًا واحدًا بديلًا، وبعدها من هذه النقطة فصاعدًا سيبقى نفس الرمز لمدة 30 دقيقة كما هو مطلوب.
