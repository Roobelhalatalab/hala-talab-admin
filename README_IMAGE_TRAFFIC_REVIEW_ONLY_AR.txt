هلا طلب – تحسين استهلاك المنيو الإلكتروني (للاختبار فقط)

المشكلة المؤكدة بالكود القديم:
المنيو كان يعيد تحميل بيانات جميع المتاجر والأقسام والمنتجات كل 60 ثانية حتى بدون تغييرات.

التعديلات:
- إلغاء إعادة تنزيل كل البيانات كل دقيقة؛ تحديث حالة الشفت عبر RPC صغير عند فتح الصفحة فقط.
- الإبقاء على تحديث البيانات بواسطة Supabase Realtime مع دمج الإشعارات المتقاربة ومنع التحميلات المتوازية.
- إضافة decoding=async لصور الأقسام والمنتجات والمتاجر لتخفيف عمل المتصفح (لا يقلل عدد البايتات بنفسه).
- تغيير رقم نسخة menu.js لمنع استعمال نسخة قديمة من كاش المتصفح.

حدود هذا التحديث:
- الكود القديم ما يزال يجلب فهارس واسعة عند فتح الصفحة أو حدوث تغيّر؛ تحسين التصفية حسب المتجر يتطلب التأكد من أعمدة الجداول وسياسات RLS بقاعدة التجربة.
- الصور الأصلية من Supabase Storage قد تكون كبيرة؛ هذا التحديث لا يغيّر حجم الملفات المخزونة ولا يضمن مقدار توفير معين.
- لم يُنشر على GitHub أو Supabase. لم يُختبر عبر متصفح حيّ أو قاعدة تجريبية.
- يرجى اختبار فتح المنيو، الشفتين، البحث، التقييم، صور المنتجات، تحديث إضافة وجبة، والرجوع قبل النشر.
