# Stage 27 FIX6 — فتح الإشعار على الصفحة الصحيحة

تم تعديل توجيه إشعارات القفل 🔐 بحيث:

- طلب **نسيت PIN للعميل** يفتح مباشرة تبويب **استرجاع PIN العملاء**.
- طلب **نسيت PIN للمتجر أو السائق** يفتح مباشرة تبويب **استرجاع PIN الشركاء**.
- طلب **انضمام متجر جديد** يفتح صفحة المتاجر ثم تفاصيل المتجر المطلوب مراجعته.
- طلب **انضمام سائق جديد** يفتح صفحة السائقين ثم تفاصيل السائق المطلوب مراجعته.
- تمت إضافة آلية Deep Link مقاومة لتأخر تحميل صفحة إدارة النظام على الأجهزة أو المتصفحات البطيئة.
