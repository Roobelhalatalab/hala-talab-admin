# هلا طلب — Admin Stage 28

## الهدف
تأسيس Responsive حقيقي للوحة الإدارة على الهاتف والآيباد مع الحفاظ على Windows ومنطق FIX10 كما هو.

## المنفذ في هذه المرحلة
- دعم viewport و safe-area لأجهزة iPhone/iPad.
- تحويل القائمة الجانبية إلى Drawer حتى قياس iPad عند الحاجة.
- تحسين Top Bar وأزرار القفل/الجرس للشاشات الصغيرة.
- جعل البطاقات والمؤشرات Responsive على الهاتف والتابلت.
- جعل الجداول قابلة للتمرير الأفقي الآمن بدل قص المحتوى.
- تحسين النوافذ والإشعارات والحقول والـtouch targets للموبايل.
- منع Zoom التلقائي على iOS عند التركيز في حقول الإدخال.
- تحسين Portrait/Landscape والمقاسات الضيقة.
- لم يتم تغيير SQL أو PIN أو Realtime أو منطق الصلاحيات في Stage 28.

## اختبار المرحلة
1. افتح index.html / start_windows.bat على Windows وتأكد أن الشكل المعتاد بقي سليمًا.
2. افتح اللوحة من هاتف أو محاكاة Responsive وتأكد أن زر ☰ يفتح القائمة ويغلقها.
3. اختبر عرض 360px و390px و430px ثم iPad 768px و1024px.
4. تأكد أنه لا يوجد قص أفقي عام؛ الجداول فقط يسمح لها بالتمرير الأفقي داخل حاويتها.

> Stage 29 مخصص لوظائف الإدارة المهمة على الهاتف (PIN/تسجيل الشركاء والتنقل المباشر) بعد نجاح هذا الهيكل.
