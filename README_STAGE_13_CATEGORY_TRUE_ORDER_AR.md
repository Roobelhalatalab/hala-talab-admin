# Stage 13 — ترتيب تصنيفات العميل بالموقع الحقيقي

- صار `sort_order` يمثل موقع الظهور الحقيقي: 1 الأول، 2 الثاني، 3 الثالث...
- تم تحويل التصنيفات الأساسية من 10/20/30... إلى 1/2/3.../8.
- التصنيفات الجديدة تبدأ بعد التصنيفات الحالية (مثلاً المخابز = 9).
- عند تعديل تصنيف مثل «ورود» من 8 إلى 2، ينتقل للمركز الثاني وتتحرك بقية التصنيفات تلقائياً لمنع تكرار أرقام الترتيب.
- عند إدراج تصنيف جديد داخل ترتيب موجود، يتم إزاحة ما بعده تلقائياً.
- الحذف يغلق فجوة الترتيب تلقائياً.
- UUID للتصنيف لا يتغير، لذلك ربط المتجر والعميل يبقى سليماً.

## قبل الاختبار
شغّل مرة واحدة في Supabase SQL Editor:

`admin_stage13_category_true_order.sql`

وتأكد أن النتيجة تعرض:

`category_true_order_ready`

بعدها افتح لوحة الإدارة، ومن «تصنيفات العميل» غيّر ترتيب أي تصنيف. تطبيق العميل يرتب من `sort_order` تصاعدياً، لذلك الرقم يظهر كموقع فعلي.
