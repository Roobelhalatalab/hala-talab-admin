# Stage 15 — إظهار التحكم بموافقة السائقين في نظرة عامة

- مبنية على Admin Stage 14.
- أضيفت بطاقة واضحة في: إدارة النظام → نظرة عامة → تسجيل السائقين.
- تعرض الحالة الحالية: مفتوح مباشرة / موافقة الإدارة مطلوبة.
- يمكن تبديل الوضع مباشرة من البطاقة بدون الذهاب إلى Supabase.
- يوجد زر للانتقال إلى إعدادات النظام الكاملة.
- نفس الإعداد `driver_approval_required` المستخدم في Stage 14؛ لا يوجد SQL جديد لهذه المرحلة إذا كان SQL Stage 14 قد شُغّل مسبقًا.
