# Admin Stage 25 FIX1 — كوبونات بعدد عملاء + تصحيح قيمة الخصم

هذا الإصلاح مبني فوق Admin Stage 25 ولا يغيّر بقية صفحات لوحة الإدارة.

## الإصلاحات
- تصحيح إدخال قيمة الخصم:
  - نسبة مئوية: من 1 إلى 100 فقط، مع توضيح (%) في الحقل.
  - مبلغ ثابت: يظهر كدينار عراقي ويقبل المبلغ مباشرة.
  - عند تبديل نوع الخصم يتغير الحقل تلقائيًا لمنع القيم غير المتوافقة.
- استبدال رسالة `INVALID_DISCOUNT_VALUE` التقنية برسالة عربية واضحة.
- الحملة المركزية أصبحت تُعرض كعدد **عملاء مستفيدين** وليس عدد طلبات.
- لكل عميل استخدام واحد فقط في الحملة المركزية.
- يمكن كتابة أي عدد يدويًا: 20، 60، 150، 500... إلخ.
- أزرار سريعة: أول 20 عميل / أول 60 عميل / أول 100 عميل.
