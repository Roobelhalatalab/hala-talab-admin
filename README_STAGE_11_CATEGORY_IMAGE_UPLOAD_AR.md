# Hala Talab Admin — Stage 11

## رفع صورة تصنيف العميل من لوحة الإدارة

تم تحويل خانة «رابط الصورة» إلى تجربة أسهل:

- اختيار صورة مباشرة من اللابتوب.
- زر **رفع صورة** يرفع الملف إلى Supabase Storage.
- الرابط العام يُملأ تلقائيًا في خانة رابط الصورة.
- تظهر معاينة للصورة عند تعديل تصنيف موجود.
- حد حجم الصورة 5 MB.
- الصيغ المدعومة: PNG / JPG / WEBP / GIF.
- الرفع والتعديل والحذف في bucket مخصص للإدارة فقط، بينما القراءة عامة حتى تظهر الصور في تطبيق العميل.

## قبل الاختبار

شغّل مرة واحدة في Supabase SQL Editor:

`admin_stage11_category_image_upload.sql`

المفروض تظهر نتيجة:

`system_category_images_ready = true`

ثم افتح لوحة الإدارة → إدارة النظام → تصنيفات العميل → إضافة تصنيف جديد.
اختر Emoji في خانة الأيقونة، ثم اختر صورة واضغط «رفع صورة»، وبعد نجاح الرفع احفظ التصنيف.
