# Admin Stage 26 — تسويات كوبونات هلا طلب مع المتاجر

هذه المرحلة مبنية فوق **Admin Stage 25 FIX3** وتضيف محاسبة واضحة للكوبونات المركزية فقط.

## ما الجديد
- كل استخدام فعلي لكوبون مركزي من هلا طلب يُسجل تلقائيًا مع:
  - رقم الطلب.
  - اسم المتجر.
  - رمز الكوبون.
  - مبلغ الخصم الذي تحمله هلا طلب.
  - إجمالي الطلب.
  - حالة الطلب.
- الطلب قبل التسليم = **بانتظار التسليم**.
- الطلب بعد `delivered/completed` = **مستحق للدفع** للمتجر.
- الطلب الملغي/المرفوض = **ملغي / لا يستحق** تلقائيًا.
- زر **تم الدفع** لا يعمل إلا بعد تسليم الطلب.
- بعد الدفع يُحفظ تاريخ الدفع ومن نفذ العملية وملاحظة اختيارية.
- يمكن إلغاء علامة الدفع إذا تم تسجيلها بالخطأ.
- أعلى الجدول تظهر المجاميع: مستحق، مدفوع، وبانتظار التسليم.
- البحث متاح برقم الطلب أو المتجر أو الكوبون، مع فلتر حالة التسوية.

## SQL
شغّل الملف التالي مرة واحدة بعد SQL الخاص بـ Stage 25:
`admin_stage26_coupon_store_settlements.sql`

الملف آمن لإعادة التشغيل ولا يحذف الطلبات أو الكوبونات أو بيانات المتاجر.
