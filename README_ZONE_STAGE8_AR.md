# المرحلة الثامنة — محرر حدود المناطق في الإدارة

- صفحة جديدة في القائمة: «رسم حدود الزونات».
- عرض حدود بخديدا وكارملش وبرطلة؛ إضافة نقاط بالسحب والنقر وحذفها واستعادة الرسم.
- الحفظ عبر RPC بصلاحيات الإدارة فقط، مع فحص صحة الرسم ومنع التداخلات.
- يحتاج تنفيذ ملف SQL بعد النسخ الاحتياطي ومراجعة مخطط قاعدة البيانات الفعلي.
- يستخدم Leaflet وخرائط OpenStreetMap عبر الإنترنت، ولا يخزن مفاتيح سرية.
- لم يتم فحص الاتصال الفعلي بقاعدة البيانات أو تشغيل اللوحة في المتصفح.
- لم يتم تغيير الطلبات أو التسعير أو الإشعارات.
