المرحلة العاشرة — تدقيق مطابقة مبالغ المناطق وأجور التوصيل (عرض فقط)
- مقارنة مجموع قيمة الطلبات وأجور التوصيل في بخديدا وبرطلة وغير المحددة بالإجمالي العام.
- تحذير واضح عند وجود اختلاف أو قيمة غير صالحة.
- كارملش تفصيل توصيل فقط ولا تُضاف مرة ثانية.
- لا تغيير على إشعارات الطلبات أو التحقق أو PIN أو Supabase أو تقارير المتاجر.
- يلزم اختبار البيانات الفعلية قبل النشر.
