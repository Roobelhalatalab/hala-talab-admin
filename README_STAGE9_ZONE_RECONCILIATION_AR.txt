المرحلة التاسعة — تدقيق حسابات المناطق (واجهة فقط)
- مطابقة إجمالي عدد الطلبات مع مجموع بخديدا وبرطلة وغير المحددة.
- تفصيل أجور توصيل كارملش حسب منطقة المتجر الأصلية، دون إضافتها للإجمالي مرتين.
- لم تتغير دوال Supabase أو الطلبات أو الإشعارات أو تقارير المتجر الشهرية والسنوية.
- يتطلب التحقق على بيانات فعلية قبل النشر.
