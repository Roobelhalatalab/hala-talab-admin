# Stage 27 FIX9 — تثبيت رمز PIN لمدة 30 دقيقة للحساب

هذا الإصلاح يعالج نقطتين معًا بدون تغيير بقية لوحة الإدارة:

1. رمز الاسترجاع صار مرتبطًا **بالحساب + الدور** لمدة 30 دقيقة من أول إصدار، وليس بطلب الاسترجاع نفسه.
2. إذا نجح تغيير الـPIN ثم ضغط نفس الحساب «نسيت PIN» بعد دقيقة أو عدة دقائق، يصل طلب جديد للإدارة لكن عند فتحه/إصدار الرمز يظهر **نفس الرمز السابق** إلى أن تنتهي الـ30 دقيقة.
3. كل ضغط جديد على «نسيت PIN» ينشئ Request ID جديدًا حتى يصل Realtime/عداد القفل كتحديث جديد ولا يضيع بسبب أن الإشعار السابق مقروء.
4. بعد انتهاء الـ30 دقيقة فقط يسمح للنظام بإنشاء رمز جديد.
5. ملف FIX9 نفسه يعيد تأكيد Realtime لجدول `phone_pin_reset_requests`، فلا يوجد SQL ثانٍ لهذه المرحلة.

## التشغيل
شغّل فقط:
`admin_stage27_fix9_pin_30min_account_window_notifications.sql`

بعدها أعد تحميل لوحة الإدارة مرة واحدة.
