# Stage 14 — مفتاح موافقة السائقين

- أضيف في إعدادات النظام كرت **تسجيل السائقين**.
- الوضع الافتراضي: **مفتوح مباشرة** (`driver_approval_required=false`).
- عند تفعيل **موافقة الإدارة** يصبح السائق الجديد قيد المراجعة إلى أن توافق الإدارة من صفحة السائقين.
- السائق الذي تمت الموافقة عليه سابقًا يبقى مقبولًا عند تفعيل المفتاح لاحقًا.
- يمكن إعادة فتح التسجيل المباشر من نفس الكرت بدون تعديل الكود.

شغّل `admin_stage14_driver_approval_switch.sql` مرة واحدة بعد تشغيل SQL الخاص بـ Partners Stage 134.
